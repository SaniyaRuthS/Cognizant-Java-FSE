angular.json: Angular workspace configuration (build, test, deploy defaults).
tsconfig.json: Root TypeScript compiler configuration.
tsconfig.app.json: TypeScript configuration specifically for the application source code.
package.json: npm dependencies and scripts for the project.
src/main.ts: The main entry point that bootstraps the Angular application.
src/app/app.config.ts: Global application configuration and providers (replaces app.module.ts in standalone mode).
src/app/app.component.ts: The root component of the application.
src/index.html: The main HTML page served by the browser.

Budgets configuration (in angular.json):
The budgets configuration under architect > build > configurations > production controls bundle size limits.
- maximumWarning: Triggers a console warning if the bundle exceeds this threshold.
- maximumError: Fails the build if the bundle exceeds this threshold.
These ensure the application remains performant and doesn't unknowingly grow too large.
